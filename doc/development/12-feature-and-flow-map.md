# 12. 功能与主链路地图

## 目标

本文件把豆屿当前五个主 Tab、跨模块流程、已有能力、半成品能力、UI-only 目标和后续优先级放在同一张工程地图里。后续开发应按本文件判断“保留并接真实接口”“标为开发态”“隐藏/禁用”的边界。

| Tab | 当前代码事实 | 最新设计目标 | 不得误导 | 后续优先级 |
|---|---|---|---|---|

## 登录态主链路

1. 未登录用户可浏览公开 Feed、作品详情、话题、贴纸、商品列表和商品详情。
2. 点赞、收藏、发帖、评论、上传、AI、购物车、订单、支付、消息、我的资产需要登录。
3. 登录请求仍传 `ageGroup=AGE_18_PLUS`。
4. Android 使用 DataStore 持久化 token，启动时 hydrate。
5. 401 或 refresh 失败必须清理本地会话，并展示统一登录引导。

禁止：

- 把 401 包装成普通空状态。
- 登录失败后继续展示“已完成操作”Toast。
- 写成登录请求已移除 `ageGroup`。

## 社区与作品详情

### 已有能力

- `GET /posts/feed`
- `GET /posts/following`
- `POST /posts`
- `GET /posts/{postId}`
- `POST/DELETE /posts/{postId}/like`
- `POST/DELETE /posts/{postId}/favorite`
- `GET/POST /posts/{postId}/comments`
- `GET /topics`
- `GET /sticker-packs`
- `GET /users/search`
- 上传链路 `/uploads/presign -> PUT -> /uploads/confirm`

### 设计目标

- 社区首页双列瀑布流，卡片图片视觉高度控制在 `120dp-260dp`。
- 作品详情顺序固定为 `图片 -> 内容 -> 评论区域 -> 悬浮评论栏`。
- 图片区必须明确是 carousel / gallery：页码、滑动提示、缩略图 strip。
- 评论区展示真实列表，不只展示输入栏。
- 评论浮动栏展开态为图片/附件预览在上，评论输入在下，工具栏在底部。

### 评论规则

- 评论可含文字、图片、@ 用户、# 话题、贴纸。
- 文本、图片、贴纸至少存在一种。
- @/# 不能单独发送。
- 图片最多 9 张。
- 图片必须上传成功并确认得到 `fileId`。
- 上传失败保留缩略图并提供重试，禁止假成功。

### 后续 P0

- 按设计重构作品详情页面。
- 把评论区、评论输入栏、@ 用户、# 话题、贴纸、图片上传失败状态全部可视化。
- 使用后端返回的 `likedByMe`、`favoritedByMe`、`followedAuthorByMe` 初始化按钮状态。

## 发帖与上传

### 已有能力

- Android 当前有 `post_create`、`image_select`、`camera_capture` 路由。
- 后端有 `POST /posts`。
- 上传链路已存在。

### 设计目标

- 新版发帖页面参考 `post-compose-a.html`。
- 覆盖图片选择、正文、话题、预览、上传中、失败重试、审核中提示。
- 发布成功后进入审核中，不假装直接公开。

### 禁止误导

- 不新增后端接口。
- 不把全局话题搜索、图片审核或草稿云同步写成已完成。

## Search

### 当前事实

没有全局搜索后端 API。当前可用相关接口：

- 用户搜索：`GET /users/search`。
- 话题搜索：`GET /topics?keyword=...`。
- 商品列表：`GET /products`，Android 当前有分类/本地筛选空间。

### 设计目标

`search-a.html` 展示：

- 返回按钮。
- 搜索输入框。
- 清空/取消。
- 范围 Tab：全部、作品、图纸、商品、用户、话题。
- 默认推荐、输入中、结果、空结果、失败、未登录受限。

### 禁止误导

- 不写全站搜索已完成。
- 不新增 Search API 字段契约。
- 如果实现本地筛选，必须在 UI 和文档中写清范围。

## 消息、通知与私信

### 已有能力

- `GET /messages/notifications`
- `POST /messages/notifications/read`
- `GET /messages/conversations`
- `GET /messages/conversations/{conversationId}`
- `POST /messages/conversations/{conversationId}`

### 设计目标

- 消息首页拆成私信和通知。
- 点击私信进入会话详情。
- 点击通知进入通知详情或详情展示状态。
- 会话详情展示互关正常聊天、未互关剩余 3 条、超过后禁用、发送失败、加载失败、空会话。

### 互关规则

- 好友第一版等价于关注/互相关注语义。
- 未互关同一发送者对同一会话最多 3 条。
- 超过后后端返回 `NON_MUTUAL_MESSAGE_LIMIT_EXCEEDED`。
- Android 必须使用 `canSend` 和 `remainingNonMutualMessages` 控制输入态。

### 禁止误导

- 不做好友申请审批。
- 通知区域不能展示会话输入状态。
- 不做图片私信、撤回和复杂已读回执。

## 我的与资料

### 当前事实

Android 当前已有：

- `profile`。
- `my_patterns`。
- `favorites`。
- `liked_posts`。
- `commented_posts`。
- `favorite_posts`。
- `followed_posts`。
- `my_orders`。
- `settings`。

后端已有：

- `GET /users/me`
- `PATCH /users/me`
- `GET /users/{userId}`
- 签到、积分、徽章接口。

### 最新设计目标

- 统计项为 `获赞 / 作品 / 关注 / 粉丝`。
- 资产 Tab 为 `我的图纸 / 点赞作品 / 收藏作品`。
- 编辑资料入口进入 `profile-edit-a.html`。
- 我的页首屏不展示“我的订单 / 评论作品 / 关注作品”。

### 边界

- 这只是目标 UI；不声明当前 Android 已删除历史路由。
- Profile Edit 已接现有 `PATCH /api/v1/users/me` 资料字段；不代表所有资料字段都有后端持久化。
- 城市/地区、定位和地图只做 UI-only 展示，不接地图 API，也不代表真实地理服务已完成。

## 商城、订单与支付

### 已有能力

- 商品列表、详情。
- 自营商品购物车。
- 创建订单、订单列表、详情、取消。
- 创建支付单、查询支付单。
- 支付回调和退款骨架在后端存在。
- Android 已用规则函数统一玩家商品标准购物车禁用、订单确认缺地址 CTA 和 `STUB` 支付边界提示。

### 关键边界

- 玩家二手/定制商品不走标准购物车和标准订单。
- 地址管理未闭环；订单确认不能伪造默认地址。
- 支付是 Stub / 联调骨架。
- `payParams.provider=STUB` 不得展示为真实支付 SDK 参数。
- 支付最终状态以服务端为准。
- 当前规则已由 JVM 测试覆盖；2026-06-05 真机 smoke 已覆盖玩家商品禁加购、自营商品可加购、购物车和订单确认地址缺口。创建订单、联调支付单和支付状态页仍未关闭，不能写成支付通过。

### 后续 P1

- 重构商城首页与商品卡。
- 统一订单确认的地址缺口状态。
- 支付页展示联调支付单、查询状态和“不确定结果”处理。

## AI 图纸

### 已有能力

- 创建任务。
- 查询任务。
- 任务列表。
- 取消任务。
- 图纸详情。
- 图纸收藏。
- 后端配额接口存在。

### 边界

- 真实视觉 Provider 未接入。
- 大模型生图 API 未接入。
- AI 首页只能表达开发态生成、排队、失败、取消、历史和结果，不承诺真实识图质量。
- Stage 8 JVM 规则测试已覆盖 AI Provider 边界文案、任务状态标签和结果页 `材料购买待接入`；这不是 AI 上传 -> 参数 -> 任务 -> 结果真机全链路通过。

### 后续 P2

- AI 首页按 `ai-home-a.html` 和 `ai-home-wireframe.svg` 收敛。
- 未来大模型生图只作为 `future-capability-ui-a.html` UI-only。

## Settings 与合规

### 设计目标

Settings 首页包含：

- 账号与安全。
- 隐私与权限。
- 通知设置。
- 内容与互动。
- 帮助与关于。
- 退出登录。
- 账号注销。

### 边界

- 隐私政策、用户协议、备案、SDK 清单、版权投诉不能写成已完成。
- 账号注销后端申请接口存在，但完整流程、冷静期、人工处理和合规闭环未完成。
- Settings 分区页已注册 Android 路由，但只做开发态 / 待补说明，不代表生产合规配置或合规材料完成。

## 未来能力 UI-only

只允许作为 UI 参考：

- 地图 API：位置授权、位置选择、无权限、定位失败、手动选择城市/区域。
- 真实支付 API：支付方式选择、支付处理中、支付失败、服务端状态查询、支付结果不确定。
- 大模型生图 API：提示词、参考图、生成中、排队中、失败重试、内容安全拦截、生成结果选择。

必须显著标注：`UI-only / 当前不接后端 / 当前不可用于真实支付或真实 AI 生成`。
