# 作品详情图片滑动与匿名互动边界优化计划

## 背景

作品详情页已经具备多图数据、左右按钮、页码和缩略图条，但主图区域仍是普通 `ImageView`，不能通过横向滑动切换图片；主图使用强裁切展示，容易出现图片被裁切或越过画廊视觉边界的问题。未登录用户应能阅读公开作品详情、评论列表和互动计数，但点赞、收藏、评论、关注等写操作必须要求登录。

## 目标

- 主图支持左右滑动切换上一张/下一张，同时保留左右按钮、点击缩略图和点击进入全屏查看器。
- 缩略图条与当前图片同步，当前图片使用粉色选中边框，并在切换后滚动到可见区域。
- 主图完整展示优先，画廊容器裁剪子视图，避免图片视觉溢出。
- 匿名用户可读取详情和评论；写操作统一走登录门禁，不做本地假成功。

## 验证

- Android JVM 契约测试覆盖触摸手势、缩略图同步、主图不使用 `centerCrop` 和匿名互动门禁。
- 后端契约测试覆盖匿名详情/评论可读，匿名点赞/收藏/评论仍返回 401。
- 完整验证记录写入 `doc/development/verification/2026-06-10-post-detail-gallery-anonymous-boundary-verification.md`。
