# 08. 商城、购物车与创建订单

## 当前范围

当前版本只保留已经闭环的购买链路：

- 商品分类和商品浏览。
- 商品详情。
- 购物车读取、添加、修改数量、删除。
- `POST /api/v1/orders` 创建订单。
- 商品详情和购物车内手填收货信息，并作为 `addressSnapshot` 提交。

当前版本不做：

- 地址簿、默认地址、地址列表、新建地址、编辑地址、删除地址、订单地址选择。
- 订单中心、订单列表、订单详情、取消订单、售后。
- 支付、退款、对账、生产回调、微信/支付宝 SDK 或 API。

## 商城首页

- 分类来自 `GET /api/v1/product-categories`。
- 商品来自 `GET /api/v1/products` 或带 `categoryId` 的过滤请求。
- 商品卡只展示后端返回的真实商品、价格、图片和库存状态。
- 空商品列表显示空态，不使用本地假商品。

## 商品详情

- 商品详情来自 `GET /api/v1/products/{productId}`。
- 数量选择必须限制在后端 SKU 可用库存内。
- 加入购物车调用 `POST /api/v1/cart/items`。
- 立即下单调用 `POST /api/v1/orders`，请求中只允许真实用户输入的 `addressSnapshot`。
- 当前版本不展示支付入口、支付参数或支付成功态。

## 购物车

- 购物车需要登录。
- 购物车数据来自 `GET /api/v1/cart`。
- 修改数量调用 `PATCH /api/v1/cart/items/{itemId}`。
- 删除调用 `DELETE /api/v1/cart/items/{itemId}`。
- 购物车下单提交选中的后端 `itemIds` 和用户手填地址快照。
- 购物车为空时显示空态，不使用本地假商品。

## 地址快照

当前版本不做地址管理。下单所需地址只来自当前页面手填字段：

- 收货人。
- 手机号。
- 地区。
- 详细地址。

这些字段组成订单 `addressSnapshot`。不得提交静态假地址、默认假地址或 `addressId`。

## 订单创建

- 服务端创建订单后状态为 `CREATED`。
- 返回订单明细、金额、地址快照和订单号。
- 客户端可以展示创建成功、订单号和 `CREATED` 状态。
- 客户端不得提供订单列表、订单详情、取消订单或支付跳转入口。

## 验收

- Android API 和 repository 只保留创建订单接口，不保留订单列表、详情或取消接口。
- `CreateOrderRequest` 不包含 `addressId`。
- 商品详情和购物车都必须手填地址并创建订单。
- Android 和后端运行时不得引入支付端点、支付页面、支付结果、虚假支付参数、退款 API 或回调路由。
