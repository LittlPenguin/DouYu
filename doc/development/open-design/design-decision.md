# 豆屿 Doyu Open Design 决策稿

> 更新日期：2026-06-09
> 当前方向：A - 内容发现 + 创作工具平衡
> 项目：SpellBean (`1a79a45f-6c02-4c3f-9433-4b27b325acf5`)

## 当前决策

第六轮页面设计继续采用 **A：内容发现 + 创作工具平衡**：

- 社区承担第一屏内容发现，使用类似小红书的双列瀑布流，但图片高度必须有上限。
- 发布入口只承载发帖，不承诺已移除的生成能力。
- 商城保持可信购买语气，玩家二手/定制不混入标准购物车。
- 消息页明确拆分私信和通知，通知不承载会话输入状态。
- 我的页收敛为轻量资产中心，不保留过多入口。

## 本轮补全

- 主页面框架统一为：左侧设置 icon、中间页面标题、右侧搜索 icon。
- 底部导航固定显示：社区、商城、上传、消息、我的；上传是 action item，点击进入全屏发帖页，不替换当前内容 Fragment。
- 底部导航补齐品牌化 Logo / icon，不使用 emoji 或纯文字占位。
- 社区首页改为双列 masonry，图片视觉高度建议控制在 120-260dp。
- 帖子详情评论栏改为 Google 风格底部悬浮栏：默认是静态 UI 输入框，点击后展开真实可输入评论框、工具栏和键盘状态。
- 评论工具全部 icon 化：图片、@、# 只出现在真实输入框内；静态输入框删除“图 / @ / # / 发送”，`#` 后不保留旧发帖入口或含义不清的额外 icon。
- 新增 Search 搜索页和上传帖子视觉参考，并为主页面搜索、底部上传、底部导航、消息列表和 Settings 列表补齐可点击去向；Search 仍无全局搜索后端，发帖使用现有 `POST /api/v1/posts`，成功后直接公开。
- 消息页补齐私信对话详情和通知详情，通知页删除会话输入状态。
- 我的页优化统计区；删除“我的订单”“评论作品”“关注作品”展示；保留“点赞作品”“收藏作品”资产 Tab。
- 我的页统计项按最新要求调整为“获赞 / 作品 / 关注 / 粉丝”，不再沿用“作品 / 获赞 / 收藏 / 关注”的顺序。
- 新增编辑资料页面 `profile-edit-a.html`，覆盖头像、昵称、简介、真实手动城市/地区、保存失败和昵称为空禁用保存状态；年龄段和兴趣标签不再出现在编辑页。
- 作品详情页顺序调整为“图片 / 内容 / 评论区域 / 底部静态输入框”，首屏先展示作品图片集合，再展示作者、标题、正文、话题和评论区。
- 作品详情主稿将点赞、评论、收藏三项可点击互动移入底部静态输入框；点击静态输入框后才展示真实可输入框、图 / @ / # 工具、发送按钮和键盘，互动计数仅作为设计稿示例，不声明真实接口已完成。
- 作品详情补齐实际评论区，包括评论标题、文字评论、含图片评论、含 @/# 的评论行、空态和加载失败状态；评论提交成功后直接刷新展示，不再要求条数展示。
- 轮播预览改为明确的 gallery / carousel：大图、`2/5` 页码、左右箭头、滑动提示、底部缩略图 strip 和当前选中边框同时出现。
- 真实输入框补齐 `@ 用户选择` 和 `# 话题选择` 状态；如 Android 未接真实搜索面板，必须开发态或禁用，不允许空点击。
- 新增 Settings 首页及账号安全、隐私权限、通知设置、帮助与关于内部入口。
- 不再保留未来能力占位页；地址管理、订单确认和发帖能力只在对应保留页面内表达当前边界。

## 页面清单

- `index.html`：Open Design 总览入口。
- `doyu-design-directions.html`：方向总览。
- `community-home-a.html`：社区首页。
- `post-detail-comment-toolbar-a.html`：作品详情评论区、轮播和评论工具条。
- `post-compose-a.html`：上传帖子视觉参考；通过底部“上传”进入，包含选图、拍照、OSS 上传、失败重试、话题选择和发布成功状态。
- `search-a.html`：Search 搜索页 UI-only 原型。
- `commerce-home-a.html`：商城首页。
- `messages-a.html`：消息首页。
- `message-conversation-a.html`：私信对话详情。
- `notification-detail-a.html`：通知详情。
- `profile-a.html`：我的页。
- `profile-edit-a.html`：编辑资料视觉参考；Android 保存头像、昵称、简介和手动城市/地区。
- `settings-home-a.html`：Settings 首页。
- `settings-account-security-a.html`：账号与安全。
- `settings-privacy-permissions-a.html`：隐私与权限。
- `settings-notifications-a.html`：通知设置。

## 不可宣称完成

- 不宣称当前发帖、订单或地址能力超出已实现接口。
- 不宣称自动地理服务或地图定位已完成；地区仅作为手动资料字段。
- 不宣称地址管理、玩家交易闭环、资金担保、提现或纠纷处理已完成。
- 不把完整上线材料写成当前范围。
- 不宣称 Android 当前代码已实现本轮所有设计稿。

## 设计约束

- 页面背景使用暖白 `#FFFBF7`。
- 主色沿用 Petal / Mint / Sky / Coral。
- 功能图标使用统一线性图标或内联 SVG/CSS 图标，不使用 emoji。
- 卡片圆角和阴影克制，避免卡片套卡片。
- 375dp 宽度下文字不溢出、底部导航不挤压、输入区不遮挡系统导航。
- 所有开发态能力必须隐藏、禁用或明确标注，不允许空点击和假成功 Toast。
