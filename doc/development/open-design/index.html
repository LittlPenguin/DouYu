方向总览

A 方向已选，B/C 只作为未来参考。

社区首页

小红书式双列瀑布流、图片高度上限、顶部新增菜单和底部 Logo 导航。

作品详情 / 评论

图片优先详情结构、点赞评论收藏操作、完整评论区、清晰 carousel、@ 用户和 # 话题选择状态。

上传帖子

从新增菜单进入的发帖视觉参考；Android 已有 post_create，生产审核和更完整多媒体能力仍未闭环。

Search 搜索页

作品、图纸、商品、用户、话题的 UI-only 搜索结构和状态。

商城首页

自营商品、玩家商品边界、真实支付 UI-only 不误导。

AI 创作首页

开发态生成、任务状态、未来大模型生图 UI-only 边界。

消息首页

私信和通知分区，通知不再出现会话输入状态。

私信对话详情

互关可发送、未互关 3 条限制、超过后输入禁用。

通知详情

评论、点赞、审核、系统通知的详情结构。

我的页

统计区为获赞、作品、关注、粉丝；我的图纸、点赞作品、收藏作品合并 Tab。

编辑资料

头像、昵称、简介、城市 UI-only、兴趣标签和保存失败状态；Android 已接现有资料保存字段。

Settings 与未来能力

Settings 覆盖必要内部页；未来地图、支付、大模型生图只做最后一轮接入前的 UI 参考。

Settings 首页

账号、安全、隐私、权限、通知、帮助、退出登录和注销。

账号与安全

手机号、登录设备、注销账号和退出登录状态。

隐私与权限

相机、相册、通知、位置权限，以及隐私开关。

通知设置

私信、评论、点赞收藏、系统通知分组控制。

关于与合规

协议、隐私政策、SDK 清单、备案等生产前待补入口。

未来能力 UI-only

地图 API、真实支付 API、大模型生图 API 的占位设计。

禁止误导

不宣称真实 AI Provider、真实微信/支付宝支付、完整地址管理、生产合规或玩家交易闭环已完成。
