# 15. AI Provider 选型与接入边界

本文件只保留 AI Provider 的当前选型结论、接入要求、降级策略和禁用方向。AI 图纸生成主流程见 `07-ai-pattern-generation.md`。

## 当前结论

豆屿 AI 拼豆图纸采用：

```text
用户图片
-> 后端上传和审核
-> 视觉理解 Provider 分析主体、构图、风险和推荐参数
-> 自研 BeadPatternEngine 裁剪、缩放、量化、真实色卡匹配和图纸生成
-> 保存预览图、色号图、材料清单、PDF
```

核心原则：

- 大模型只做视觉理解和预处理建议，不作为最终图纸生成引擎。
- 最终拼豆图纸必须由后端自研算法生成，保证色号、豆量、尺寸和材料清单可控。
- 客户端不得直连 AI Provider。
- Provider 失败不能导致任务系统不可恢复，必须有失败原因、重试或降级。

## 当前实现状态

已完成：

- `AiVisionProvider` 抽象。
- `ImageAnalysisResult` 和 `ImagePrepareResult` 结果模型。
- Stub Provider。
- Provider Router。
- AI 调用缓存。
- AI 调用额度和成本记录。
- BeadPatternEngine：CIEDE2000、多色卡、难度、风格、色号图、材料清单。
- PatternJobExecutor：异步任务、进度追踪、结果保存和 PDF 生成。

未完成：

- `AliyunBailianProvider` 真实 API 调用。
- 通义万相或其他图像预处理真实接入。
- Provider 真实错误码映射、限流、重试、熔断和监控。
- Provider 成本按真实模型计费统计。
- 输入/输出图像审核的生产级接入。

## Provider 优先级

优先接入顺序：

1. 阿里云百炼 Qwen-VL：视觉理解、主体识别、构图建议、风险标记。
2. 通义万相或同厂商图像能力：可选的清背景、低细节化、风格预处理。
3. 火山引擎、腾讯混元、百度千帆：作为备选 Provider，不作为当前默认主链路。

选择理由：

- 中国大陆可用性和合规路径更清晰。
- 与对象存储、内容安全、计费和运维体系更容易统一。
- 视觉理解结果可以结构化传给自研拼豆算法。

## 接口边界

Provider 分析输入：

- 文件存储 Key 或后端可访问的文件引用。
- 用户选择参数：风格、难度、拼豆规格、目标尺寸、色卡。
- 任务上下文：用户 ID、任务 ID、traceId。

Provider 分析输出必须结构化：

- 主体描述。
- 主体类型。
- 清晰度。
- 背景复杂度。
- 推荐裁剪区域。
- 推荐风格和难度。
- 推荐格数和颜色数量。
- 适合度评分。
- 风险标记。
- 用户可读建议。

Provider 不负责：

- 生成最终拼豆网格。
- 直接决定订单、材料 SKU 或价格。
- 绕过后端审核。
- 直接向客户端暴露密钥、原始响应或供应商错误细节。

## 生产接入要求

真实 Provider 接入前必须完成：

- API Key 和模型配置通过环境变量或密钥管理注入。
- 请求超时、连接超时、重试次数和最大并发可配置。
- Provider 原始响应只写安全日志，不记录敏感图片内容或密钥。
- 错误码映射到内部可控错误：超时、限流、审核拒绝、格式异常、供应商故障。
- 每次调用记录 traceId、jobId、provider、model、耗时、成功状态和估算成本。
- 同一输入和参数短时间内命中缓存，避免重复计费。
- Provider 调用失败时任务进入可解释状态，不返回假成功。
- 生产开关必须能一键回退到 Stub 或降级策略。

## 降级策略

允许的降级：

- 视觉 Provider 失败时，使用用户参数和默认裁剪继续执行基础拼豆算法，并标记分析缺失。
- Provider 超时时，任务可失败并提示稍后重试。
- 准备图失败时，保留原图进入算法，但记录预处理失败原因。

不允许的降级：

- Provider 失败后伪造“真实 AI 分析成功”。
- 内容审核失败后继续生成公开结果。
- 因成本或超时绕过用户额度和任务状态记录。
- 客户端直接调用第三方模型补偿后端失败。

## 禁用方向

- 不把 Agent 平台作为第一版生产主链路的唯一依赖。
- 不训练自有大模型作为当前阶段目标。
- 不让大模型直接输出最终可购买材料清单。
- 不把未审核图片、儿童/隐私高风险图片、版权高风险图片直接用于公开展示。
- 不在客户端保存或传递任何 AI Provider Key。

## 验收

真实 Provider 接入完成后至少验证：

- 清晰头像、宠物、二次元图、低清图、背景复杂图、违规图。
- 成功、超时、限流、供应商错误、返回 JSON 异常。
- Provider 失败后任务状态、用户提示、traceId 和重试行为正确。
- 成本和额度记录准确。
- 相同输入和参数可命中缓存。
