> 更新日期：2026-06-04

Open Design 当前协作项目为 `SpellBean`（项目 id：`1a79a45f-6c02-4c3f-9433-4b27b325acf5`，入口文件：`index.html`）。用户已选择 **A：内容发现 + 创作工具平衡** 作为第六轮页面设计方向；后续 Compose 落地默认按该方向收敛，不再混用 B/C 视觉语言。

## 总体 UI 原则

- 第一屏必须是可用 App 体验，不做营销落地页。
- 视觉方向是“拼豆小岛”：轻盈、精致、年轻女性友好，但不幼稚。
- 第六轮当前视觉方向为 A：社区内容发现优先，AI 是清楚的创作工具区，商城保持克制可信，消息和我的页突出状态与资产边界。
- 页面背景使用暖白 `#FFFBF7`，内容表面以白色和浅粉/薄荷/天蓝容器区分状态。
- 主色只做品牌和选中强调，不大面积铺满页面。
- 图标使用统一线性图标或 Compose Material Icons，不使用 emoji 作为功能图标。
- 卡片用于内容项、工具面板、弹窗和确实需要框定的信息；不要卡片套卡片。
- 所有页面覆盖加载、空、失败、未登录、禁用状态。
- 未闭环能力隐藏、禁用或明确开发态说明，不能空点击或假成功。

## App Shell 蓝图

主 Tab：

| Tab | 页面角色 | 首屏重点 |
|---|---|---|
| 社区 | 内容发现和互动入口 | 统一顶部栏、频道、双列瀑布流、发布入口 |
| 商城 | 材料购买和玩家商品展示 | 搜索、分类、Banner、双列商品卡、购物车入口 |
| AI 拼图 | 图纸生成工具入口 | AI Hero、上传入口、正在生成任务、历史图纸 |
| 消息 | 通知和私信入口 | 通知/私信 Tab、未读状态、互关私信边界 |
| 我的 | 个人资产中心 | 资料、统计、我的图纸/收藏/订单/互动作品 |

底部导航：

- 固定 5 个 Tab。
- 每个 Tab 必须有品牌化 Logo / icon：社区、商城、AI、消息、我的均不能只显示文字或空框。
- 选中态使用浅粉容器、深粉图标和短指示条；图标语义保持“拼豆小岛”方向。
- AI Tab 可用 `AutoAwesome` / 星形创作图标，但不能破坏整体底栏一致性。
- 详情页、流程页、订单确认、支付状态、会话详情、AI 参数/进度页隐藏底栏。

主页面顶部栏：

- 五个主 Tab 顶部统一为：左侧 `新增 icon`、中间页面标题、右侧 `搜索 icon`。
- 点击 `新增 icon` 打开下拉快捷菜单，固定包含 `Setting`、`AI 创作`、`上传帖子`。
- 快捷菜单必须有真实跳转、禁用态或开发态说明，不允许空点击。
- 搜索入口进入 `search-a.html`。若未接真实搜索，必须明确开发态或只做本地筛选，不写成全站搜索已完成。

交互去向：

| 入口 | Open Design 去向 | 规则 |
|---|---|---|
| 主页面搜索 icon | `search-a.html` | 全局搜索 UI-only 或本地筛选，不声明后端已完成 |
| 新增菜单 / Setting | `settings-home-a.html` | Settings 入口必须可进入或明确开发态 |
| 新增菜单 / AI 创作 | `ai-home-a.html` | 回到 AI 主页面，不空点击 |
| 新增菜单 / 上传帖子 | `post-compose-a.html` | 发帖 UI-only 或真实发帖流程，不假成功 |
| 底部导航 | 五个主 Tab 互跳 | 社区、商城、AI、消息、我的均有品牌化 icon |
| 私信行 | `message-conversation-a.html` | 私信状态只在对话详情表达 |
| 通知行 | `notification-detail-a.html` | 通知详情不出现会话输入状态 |
| Settings 行 | 对应 Settings 内页 | 合规入口标待补，不写成生产完成 |

## 社区首页

首屏结构：

1. 顶部主栏：左侧新增 icon，中间“社区”，右侧搜索 icon；新增菜单含 Setting、AI 创作、上传帖子。
2. 频道 Tab：推荐、关注、教程、图纸等轻量 Chip，选中态清楚。
3. 内容流：双列瀑布流作品卡，优先展示真实图片；图片缺失时使用 swatch/占位。
4. 作品卡：图片、标题、作者、点赞/收藏/评论计数。
5. 发布 FAB：只用于发帖，点击必须进入真实发帖流程或登录引导。

瀑布流规则：

- 作品流采用类似小红书的双列 masonry，不同图片比例形成竖向错落。
- 图片视觉高度建议控制在 120dp-260dp；超出上限裁切，不撑高页面。
- 标题最多两行，作者和互动数据固定层级，动态文案不得推挤底部导航。
- 瀑布流是 UI 目标，不代表当前 Android 代码已经实现。

状态：

| 状态 | 展示 |
|---|---|
| 加载 | 拼豆点阵 skeleton 或轻量进度 |
| 空 | 说明当前频道暂无作品，并提供刷新或去发布 |
| 失败 | 用户可读错误 + 重试；有 traceId 时低优先级展示 |
| 未登录 | 推荐 Feed 可看；关注 Feed、发布、点赞、收藏进入登录引导 |
| 图片失败 | 保持卡片尺寸，回退到色块或占位，不挤压布局 |

禁止：

- 不做复杂推荐承诺。
- 不展示空点击话题或热榜。
- 不把审核中内容写成立即公开。

## 帖子详情与评论工具条

详情结构：

1. 顶部返回栏：标题简洁，避免大面积品牌装饰。
2. 图片集合：大图优先展示，支持 `2/5` 页码、左右切换箭头或滑动提示、底部缩略图 strip 和当前选中边框。
3. 内容区：作者头像、昵称、关注/已关注/互相关注状态、标题、正文、话题、关联图纸。
4. 互动区：点赞、收藏、评论计数，使用 `likedByMe`、`favoritedByMe`、`followedAuthorByMe` 初始化。
5. 评论区：标题、评论数量、评论列表、文字评论、含图片评论、含 @/# 的评论行、空态和加载失败。
6. 底部评论工具条。

本页顺序必须是 `图片 -> 内容 -> 评论区域`。旧的 `内容 -> 图片 -> 评论区域` 只作为历史问题记录，不再作为目标设计。

评论工具条采用 Google 风格悬浮栏：

| 状态 | 结构 |
|---|---|
| 折叠态 | 悬浮在底部安全区上方的轻量胶囊；中间“写下你的评论”；右侧保留展开入口；不展示发送按钮 |
| 展开态 | 胶囊平滑增高为浮动面板；上方图片/附件缩略图和 @/# Chip 行；中间 3-6 行输入；底部 icon-only 图片、@、# 工具；右侧清空/发送 |
| 无上传图 | 只显示输入框和 icon 工具栏 |
| 一张图 | 显示单张缩略图和 `1/9` 计数 |
| 多图堆叠 | 缩略图叠放显示，点击进入轮播 / gallery 预览 |
| 轮播预览 | 大图 + `2/5` 页码 + 左右箭头/滑动提示 + 底部缩略图 strip + 当前图选中边框；删除图片不清空文字、@、# |
| 发送中 | 禁用发送和重复提交，展示进度 |
| 上传失败 | 阻断提交，保留已选图片/@/#，展示可读错误 |
| 发送成功 | 提示等待审核，清空输入并回到折叠态 |
| @ 用户选择 | 搜索输入、用户结果、已选择用户 Chip、空结果、加载失败 |
| # 话题选择 | 话题搜索、热门/推荐话题、已选择话题 Chip、空结果、开发态边界 |

规则：

- 最多 9 张图片。
- 文字、图片至少一种存在时才启用发送。
- 图片、@、# 工具必须使用 icon 按钮；不使用“图 / @ / # / 帖子”等文字按钮，并删除“帖子”入口。
- 展开态统一为图片/附件预览在上、评论输入内容在下、工具栏在底部；`#` 后不得保留旧发帖入口或含义不清的额外 icon。
- @、# 必须打开真实搜索/选择面板或明确开发态，不能空入口；如 Android 未接真实面板，必须禁用或展示开发态说明。
- 点击详情内容区、发送成功、清空或失焦后可收起；内部工具按钮不能被失焦逻辑抢先打断。

## 发帖页

结构：

1. 顶部返回 + 发布按钮。
2. 标题输入。
3. 正文输入。
4. 图片选择与上传状态。
5. 话题选择。
6. 关联图纸入口，如未闭环则隐藏或禁用。

状态：

- 上传失败必须可重试。
- 发布后进入审核中，不立即公开。
- 未登录进入登录引导。

禁止：

- 不做视频发布承诺。
- 不用 Toast 假装发布成功但不改变状态。
- Open Design 原型 `post-compose-a.html` 只作为 UI-only 发帖设计参考；未接 Android / 后端时，不得写成上传帖子已完成。

## Search 搜索页

Search 页面承接所有顶部搜索 icon，是全局搜索体验的 UI-only 蓝图。

首屏结构：

1. 顶部返回栏：返回来源页，右侧可保留 Settings 或取消动作。
2. 搜索输入框：搜索作品、图纸、商品、用户、话题；支持清空。
3. 范围 Tab：全部、作品、图纸、商品、用户、话题。
4. 默认推荐：只展示推荐词或最近搜索，不写成真实热榜。
5. 结果列表：不同类型使用不同卡片，并有明确点击去向。

状态：

| 状态 | 展示 |
|---|---|
| 默认 | 推荐词、最近搜索、开发态说明 |
| 输入中 | 联想建议或本地筛选提示 |
| 有结果 | 作品、图纸、商品、用户、话题卡片 |
| 空结果 | 清空搜索、换关键词、返回推荐 |
| 加载失败 | 可重试，不吞成空白 |
| 未登录受限 | 公开内容可看，用户/私信相关结果折叠或提示登录 |

禁止：

- 不新增后端 API 字段或路径。
- 不宣称全站搜索、个性化热榜、用户搜索或话题搜索已完成。
- 搜索范围不能空点击；未接入时必须禁用或标注开发态。

## 商城首页

首屏结构：

1. 顶部搜索栏：搜索商品名、色号、工具。
2. 品类 Chip：豆子、色卡、板子、工具、套装、玩家商品。
3. Banner：只放真实可解释活动或推荐，不放不可点击假活动。
4. 商品双列卡：图片、标题、类型、自营/玩家标签、价格、库存/销量辅助信息。
5. 购物车入口：只对自营标准商品保留。

商品类型展示：

| 类型 | 展示规则 |
|---|---|
| `SELF_OPERATED` | 可进入标准购物车和订单链路 |
| `PLAYER_SECOND_HAND` | 只展示商品信息和直连/开发态边界，不进入标准购物车 |
| `PLAYER_CUSTOM_SERVICE` | 只展示定制服务信息和沟通边界，不进入标准购物车 |

状态：

- 商品图缺失时使用稳定占位，不让卡片高度跳动。
- 搜索空态提供清除搜索或返回推荐。
- 未登录加购进入登录引导。

## 商品详情 / 购物车 / 订单确认

商品详情：

- 图片、标题、类型、价格、规格、库存、详情说明。
- 自营商品展示加购物车；玩家商品禁用标准加购并说明边界。
- 价格和库存必须高可读，不用过度卡通表达。

购物车：

- 展示自营商品、数量、金额、库存状态。
- 数量调整、删除、结算必须有明确反馈。
- 玩家商品不得混入标准购物车。

订单确认：

- 明确展示地址缺口。
- 地址管理未闭环前，禁止伪造默认地址和伪下单。
- 订单金额以服务端为准，客户端不自行决定最终金额。

支付状态：

- 只展示“联调支付单 / 服务端确认状态”。
- 不展示正式微信/支付宝成功态。
- 提供返回订单或刷新状态。

## AI 创作页

首屏结构：

1. AI Hero：说明开发态图纸生成，不承诺真实视觉理解质量。
2. 上传入口：相册、拍照。
3. 正在生成任务卡：进度、状态、取消。
4. 创作历史：图纸预览、状态、材料摘要。
5. 失败/取消/成功入口。

参数页：

- beadSize、targetSize、difficulty、paletteId、style。
- 选择控件稳定，不因文案变长挤压。
- 参数不完整时禁用创建。

进度页：

- 显示 PENDING/PROCESSING/SUCCEEDED/FAILED/REJECTED/CANCELED。
- 失败原因可读，有重试或返回路径。

结果页：

- 图纸预览、色号图、材料清单、保存。
- 加购、PDF、分享到社区未闭环时禁用或明确开发态。

## 消息页

首屏结构：

1. 顶部主栏：左侧新增 icon，中间“消息”，右侧搜索 icon。
2. Tab：通知、私信。
3. 通知列表：类型、标题、摘要、未读强调、时间。
4. 私信列表：对方、最后消息、未读、互关/剩余条数提示。

点击规则：

- 私信行进入 `message-conversation-a.html` 对话详情。
- 通知行进入 `notification-detail-a.html` 通知详情。
- 通知列表不得展示“会话输入状态”；新消息、输入状态、剩余条数和禁发态只属于私信。

会话详情：

- 文本消息气泡。
- 输入框仅在 `canSend=true` 时启用。
- 未互关剩余条数展示为轻提示。
- 超过 3 条时禁用输入并提示“互相关注后可继续聊天”。

禁止：

- 不做图片私信。
- 不展示复杂已读。
- 不做发送假成功。
- 不展示好友申请审批状态。

## 我的页

首屏结构：

1. 个人资料：头像、昵称、简介、等级。
2. 统计：获赞、作品、关注、粉丝。
3. 资产 Tab：我的图纸、点赞作品、收藏作品放入同一个 Tab 区。
4. Tab 内容：统一显示图纸卡或帖子卡，可进入对应详情。
5. 编辑资料：资料区“编辑资料”进入 `profile-edit-a.html`，未实现时明确 UI-only / 开发态。
6. Settings：优先从主页面新增菜单进入；资料区可保留低优先级设置入口，但不能空点击。

最新设计目标：

## 编辑资料页

`profile-edit-a.html` 是我的页“编辑资料”的 UI-only 原型，不新增 Android 路由、保存接口或地图定位能力。

首屏结构：

1. 顶部返回栏：左侧返回我的页，中间“编辑资料”，右侧保存。
2. 头像编辑：展示当前头像、更换头像入口、上传中和失败重试。
3. 昵称：必填；为空时禁用保存。
4. 简介：多行文本，保存失败时保留草稿。
5. 年龄段：只展示当前 16+ / 18+ 等资料口径，不做实名。
6. 城市 / 地区：手动选择或展示 UI-only，不请求真实地图 API。
7. 兴趣标签：轻量 Chip，可增删但不声明已接真实接口。

状态：

| 状态 | 规则 |
|---|---|
| 默认编辑 | 所有字段可见，保存按钮按字段合法性启用 |
| 头像上传中 | 保存禁用，展示上传中状态 |
| 头像上传失败 | 保留旧头像，提供重试和删除新图 |
| 昵称为空 | 保存禁用，展示可读错误 |
| 保存中 | 禁止重复点击 |
| 保存失败 | 保留草稿，不返回我的页 |
| 保存成功 | 返回我的页并刷新资料区 |

禁止：

- 不新增实名、地址、隐私合规或地图定位承诺。
- 不把城市/地区写成已接真实地理服务。
- 不把本页写成 Android 当前已实现。
